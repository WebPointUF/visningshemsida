# Visningshemsida

Exempel på hur en enkel hemsida för en lokal företagare kan se ut. Samma mall visas som tre olika branscher:

- **Café** – Kafé Linden
- **Hantverkare** – Berg Bygg & Snickeri
- **Bilverkstad** – Nilssons Bilverkstad

Byt bransch med knapparna högst upp, eller direkt via länk: `index.html#cafe`, `#hantverkare`, `#mekaniker`.

## Innehåll
Startsektion, tjänster/meny med priser, om oss, kundomdömen, kontakt med öppettider (dagens rad markeras) och kontaktformulär (demo, skickar inget). Mobilanpassad med hamburgermeny.

## Anpassa till en kund
Alla texter, priser och öppettider ligger i `script.js` (objektet `content`). Färger per bransch finns överst i `styles.css`.

Öppna bara `index.html` i en webbläsare – inget byggsteg behövs. Alla namn och uppgifter är påhittade.
